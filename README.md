## Деплой

Сайт развёрнут на VPS под управлением **nginx**.

### Нетривиальная часть

На том же сервере работает защищённый прокси-сервис, который занимает стандартный HTTPS-порт.  
Чтобы сайт был доступен по `https://` без конфликта портов, использована техника **TLS Fallback**:

- Входящий TLS-трафик на порту 443 анализируется по первому байту
- Если это запрос от прокси-клиента — обрабатывается прокси-сервисом
- Если это обычный браузер — трафик перенаправляется на nginx (внутренний порт, недоступный снаружи)

Таким образом **один порт обслуживает два независимых сервиса** без конфликтов.
